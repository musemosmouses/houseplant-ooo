One original out-of-office auto-reply, written as if a houseplant sent it — ignored since March, last watered in March, still turning sunlight into spite.

> I'm out of office until someone remembers I exist. Last watered: March. Morale: photosynthesizing out of spite.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 111 characters, within the 120-character cap.
